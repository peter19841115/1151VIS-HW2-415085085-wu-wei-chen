三、設計理念與圖表選擇

這次作業使用的是 JNTO 歷年訪日旅客的統計資料。為了讓資料更容易閱讀，我主要實作了兩個分頁、兩種不同的圖表來呈現

為什麼選堆疊長條圖

我選擇堆疊長條圖，因為它可以一眼看出每年總人數的起伏（像是 2020 疫情暴跌，到 2024、2025 的爆發性回溫），同時又能看到各國的佔比。比起圓餅圖只能看單一年份，用長條圖來比較「時間趨勢」直覺很多。
排版與互動設計

長條圖裡面的顏色區塊是固定順序的（例如南韓固定在最下面），這樣眼睛在看的時候比較好追蹤同一個國家這幾年來的變化。

但因為固定順序很難一眼看出「當年誰是第一名」，所以我另外在下方做了一個互動表格。只要點擊某個年份的柱子，下方就會自動展開那一年的詳細排名跟確切數字。這樣既保留了圖表的視覺連續性，也補足了精確數據的需求。

最後考量到 2020–2022 年受疫情影響，訪日旅客數量急劇萎縮（部分國家數據甚至趨近於零），若採嚴格的絕對線性比例繪製，該區段的長條會過於扁平而難以點擊或互動。因此，本專案在長條渲染邏輯中加入了最小視覺高度的保護機制，確保在維持客觀數據比例的同時，使用者仍能順利進行滑鼠懸停與點擊年份展開詳細數據表格的互動。

四、資料觀察與結論

資料來源：日本政府觀光局 (https://www.jnto.go.jp/statistics/data/visitors-statistics/) 這一頁的  時系列推移表  底下的  国籍/月別 訪日外客数（2003年～2026年）（Excel） 下載資料

透過這次的視覺化圖表，可以發現幾個重點：

1.	亞洲鄰國絕對是主力：東亞的南韓、台灣、中國、香港長期佔了訪日旅客大約 60% 到 70%。特別是疫情解封後，台灣跟南韓的回溫速度非常驚人。
2.	疫情影響與復甦：2020 和 2021 年因為邊境管制，人數幾乎歸零。但到了 2024、2025 年已經完全超越 2019 年疫情前的高峰（2025 年光是南韓就突破 940 萬、台灣也破 670 萬人次）。
3.	歐美市場穩定成長：美、加、澳雖然總人數不及亞洲國家，但近幾年的成長曲線也很穩定。

五、技術與實作過程
這次作業前端是用 Vue 3 搭配 Vite 5 寫的。
做出的主要互動功能包含：
•	切換視角：可以一鍵切換看「萬人次總數」或「100% 堆疊比例」。
•	圖例過濾：點上面的國家名稱，可以把特定國家隱藏，圖表會自動重算比例。
•	Tooltip 提示：游標移到顏色區塊上，會精準抓取座標並顯示當年的確切數字跟市佔率。
•	點擊聯動表格：點擊長條圖，下面馬上展開詳細的降冪排名表格。
•	動態競速圖：另外做了一個 Bar Chart Race 分頁，可以按播放鍵看 2010 到 2025 的動態排名變化。
